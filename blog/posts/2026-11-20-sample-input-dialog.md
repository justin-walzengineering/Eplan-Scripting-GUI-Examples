# A friendly input dialog for your Eplan scripts

Scripting is one more way to shape Eplan around how you work. A good first step is a small window that asks for a value.

## What you will learn

- How a Windows Forms dialog is built in a script
- How to handle Cancel and empty input politely

## Try it

The full, commented example is in the repository under `examples/01-input-dialog`.

Questions or ideas for another example? Open an issue on the repository.
