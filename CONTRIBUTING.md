# Contributing

Thanks for helping make Eplan scripting easier to learn. Questions, bug reports, and ideas are all welcome.

## Ways to help

- **Ask a question or share an idea** in Discussions.
- **Report a bug or unclear explanation** as an Issue. Include your Eplan version and what you expected to happen.
- **Suggest a new example** as an Issue labeled `idea`.
- **Send a pull request** for a fix or a new example.

## The one rule: original work only

Only submit code and text you wrote yourself. Do **not** include:

- Eplan training material, class examples, or documentation text
- Eplan DLLs, templates, or other Eplan-owned files
- Code from your employer or customers, or anything containing their data

Every pull request includes this checkbox, and by ticking it you confirm it:

- [ ] This is my own original work. It contains no Eplan-owned material and no confidential employer or customer material.

By contributing you agree your work is released under the [MIT license](LICENSE).

## Example guidelines

- One idea per example. Small and readable beats clever.
- Use the header format and folder layout described in [CLAUDE.md](CLAUDE.md).
- Explain the basic C# for beginner examples.
- Use made-up sample data.
- Test in Eplan 2026 if you can, and say which version you tested.
- Be kind. Everyone here started somewhere.

The maintainer reviews every pull request and may ask for changes.
